# TOEIC BEAT 問題の移植

取得元：`yuuuh26/toeic-beat` の `words.json`。
参照コミット：`1df60ed437ca03e6681c866f8435a959557df972`。
元の500語を `data/toeic-beat.json` に保存。単語・意味・発音記号・品詞・レベル・分類・例文2件と訳・コロケーション・ノート・同義語・除外する意味を変更せず保持します。

`js/content.js` がRECALL BURST形式へ変換。1つのジャンルで全500語、または元のLEVEL 1〜5（各100語）を選べます。出題方向と習熟度はRECALL BURSTのものを使用し、TOEIC BEATの端末内成績にはアクセスしません。

4択の誤答候補は元アプリと同様、同じ品詞を優先し、同分類を先に選び、同義語と除外指定の意味を避けます。逆方向では同じ日本語の意味を持つ単語も除外します。

内蔵問題集は一度だけ追加します。既存問題・設定・成績・履歴を上書きしません。追加後に編集・削除した問題を再起動で戻しません。今後の問題集は通常のジャンル作成・JSONインポート、または `data/packs.json` に新しい独立パックを登録して追加できます。
